# تغییرات واردکننده MetaTrader و ریسپانسیو وب

## علت نبودن Import در نسخه وب

قابلیت ورود CSV در سند محصول ذکر شده بود، اما در سورس اولیه هیچ صفحه، سرویس parser، فایل‌پیکر یا تابع ذخیره‌سازی برای آن وجود نداشت. بنابراین هنگام تبدیل به وب چیزی غیرفعال نشده بود؛ این قابلیت عملاً هنوز پیاده‌سازی نشده بود.

## قابلیت جدید Import

- ورود گزارش‌های رایج MetaTrader 4 و MetaTrader 5
- پشتیبانی از CSV، TSV، TXT و گزارش HTML
- تشخیص خودکار جداکننده و نام ستون‌ها
- تشخیص BUY/SELL، نماد، حجم، قیمت ورود/خروج، SL/TP، زمان‌ها، کمیسیون، Swap و سود/زیان
- گروه‌بندی Dealهای MT5 با Position ID و ساخت معامله کامل
- پیش‌نمایش قبل از ثبت
- جلوگیری از ثبت تکراری معاملات
- ساخت خودکار نماد سفارشی برای نمادهای ناشناخته بروکر

مسیر استفاده:

`Settings > Data > ورود خودکار از MetaTrader 4/5`

## اصلاحات ریسپانسیو

- محاسبه عرض واقعی محتوا با کسر عرض Sidebar در دسکتاپ
- فعال شدن Sidebar از عرض 900 پیکسل به بالا
- رفع overflow نمودارهای Analytics
- چیدمان ستونی اکشن‌ها و کارت‌ها در موبایل باریک
- Modalهای مناسب دسکتاپ و Bottom Sheet مناسب موبایل
- wrap شدن KPIها، دکمه‌ها و بخش‌های تنظیمات
- محدود کردن عرض محتوا روی نمایشگرهای بسیار عریض

## بررسی فنی

فرمان زیر با موفقیت اجرا شده است:

```bash
npm run check
```

شامل TypeScript type-check و Expo production web build.

## محدودیت قالب فایل

Parser قالب‌های رایج خروجی MT4/MT5 را پوشش می‌دهد. بعضی بروکرها ستون‌های سفارشی یا نام‌گذاری متفاوت دارند. در صورت شناسایی نشدن فایل، یک نمونه گزارش بدون اطلاعات حساس برای توسعه parser لازم است.
