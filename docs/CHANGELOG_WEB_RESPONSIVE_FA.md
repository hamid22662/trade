# اصلاحات نسخه وب TradeLog

تاریخ: 2026-07-17

## قابلیت‌های فعال‌شده

- گزینه اعلان‌ها در نسخه وب دیگر مخفی یا غیرفعال نیست.
- اجازه اعلان مرورگر با اقدام مستقیم کاربر درخواست می‌شود.
- یادآور روزانه تا زمانی که وب‌اپ باز است اجرا می‌شود.
- تنظیمات اعلان مانند نسخه موبایل در دیتابیس محلی مرورگر ذخیره می‌شود.

> برای اعلان کاملاً پس‌زمینه در زمانی که مرورگر بسته است، در فاز بعد باید Web Push سمت سرور اضافه شود.

## اصلاحات ریسپانسیو

- دسکتاپ: منوی کامل کناری برای هر شش بخش برنامه.
- موبایل: منوی پایین فشرده و سازگار با صفحه‌های کوچک.
- تبلت و دسکتاپ: محدودشدن عرض محتوا و فاصله‌گذاری متناسب.
- نمودارهای Analytics با تغییر اندازه پنجره دوباره اندازه‌گیری می‌شوند.
- پنجره انتخاب نماد، مرتب‌سازی و افزودن نماد روی دسکتاپ عرض کنترل‌شده دارند.
- کارت‌های پلن اشتراک روی دسکتاپ دو ستونه و روی موبایل تک‌ستونه هستند.
- اکشن ثابت پایین صفحه در دسکتاپ با محتوای اصلی هم‌تراز شده است.

## باگ‌های رفع‌شده

- خطای `Invalid style property of direction`.
- هشدار منسوخ‌شدن `props.pointerEvents` در کامپوننت‌های داخلی.
- هشدارهای shadow قدیمی در React Native Web برای کامپوننت‌های مشترک.
- درخواست خودکار مجوز اعلان بدون تعامل کاربر در مرورگر.
- فعال‌ماندن تنظیم اعلان پس از رد مجوز مرورگر.
- Redirect تأیید ایمیل به آدرس جاری وب‌اپ.
- حذف اشتباه فایل‌های عکس هنگام Restore بکاپ ابری.
